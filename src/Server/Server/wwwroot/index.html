Emulator Online Multiplayer — two players

Own STUN/TURN servers (Direct only, optional)

Empty = built-in free servers. Saved in this browser only. Each player sets their own.

Enter a room code, pick your ROM and press Join.
  • Both players pick the same connection. Direct pairs the two browsers through the free PeerJS server and then sends everything between them, which is the fastest; if a network blocks that it falls back to a free relay, or pick Server relay.
  • First to join a room is player 1, second is player 2. Both use the normal EmulatorJS keys (arrows, Enter = Start, Z / X / S ...) or a gamepad on their own machine. Click the game screen first.
  • Keep this tab visible: a hidden or minimised tab stops rendering frames, which pauses the game for both players.
  • Do not use save/load state, restart, fast forward, rewind or cheats: they change one side only and cause a desync.
  • Needs internet: EmulatorJS and the core load from cdn.emulatorjs.org. The ROM never leaves your browser; only a hash of it is compared.
